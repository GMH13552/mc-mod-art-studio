# 任务
生成一个 item 的 Minecraft 资源：异形水晶法杖 (Alien Crystal Wand)

# 设计要点（先理解，再直接输出）
- 语义：一根以法杖为语义骨架、顶端长着多根尖柱状异形水晶簇的 Minecraft 物品；整体沿同一条对角线构图，水晶簇锚定在杖身顶端，视觉主体是水晶簇，不是简单火焰棒。
- 调色板（直接使用 #RRGGBB，至少 5~8 色）：base=#3E8F84 light=#8FCEC4 dark=#16403C accent=#C9A227 outline=#10282A
  描边：水晶外轮廓用 1px 深色描边 #10282A；杖身与水晶之间用暗棕/深绿自然分隔；描边沿对角线构图走。
  饱和度：青绿/水晶色整体降低饱和度，避免高饱和荧光；亮部仅作局部 1px 提示。
- 形状：沿左下→右上的斜向细杖 + 顶端水晶簇：杖身顶端即水晶簇锚点，中央主水晶与杖身同轴，左右副水晶分叉；整体是一条连续斜向‘法杖’剪影。
- 方位/构图：整根法杖为一条从‘左下→右上’的对角线构图；杖身与杖头必须沿同一条轴线
- 连接：连接处位于杖身顶端端点，且与杖身轴线重合；严禁‘手柄斜、杖头正’或连接点偏到侧面
- 轴线检查：从杖尾到杖头用一条假想对角线贯穿，任何部件（握柄、杖身、中央主水晶）都不得偏离该轴线
- 形状-纹样一体：
  · crystal_cluster 水晶簇：形状=多根尖柱/棱面尖柱（中央主晶与杖身同轴） 纹样=棱面 + 纵向高光带 + 两侧暗面 走向=每根尖柱从尖端到底座都有一条沿柱体轴向（即杖身对角线方向）的纵向高光带；中央主晶与杖身同轴，暗面位于柱体两侧。
  · rod 杖身：形状=2-3px 宽斜向细杖（左下→右上） 纹样=暗棕颗粒 / 微弱魔法纹 走向=颗粒与魔法纹沿杖身轴线纵向流动，不出现横向/竖直孤立纹样。
  · handle 握柄：形状=杖身下段加粗/深色段 纹样=暗棕分段 + 颗粒 走向=分段线沿握柄径向环绕，颗粒沿握柄纵向分布；整体仍在同一对角线上。
- 设计自检（输出前逐项自查）：方位/构图一致性；连接点对齐；语义可辨；配色层次；纹样与形状一体；边框/背景
- 参考节点（仅语义参考，禁止复制像素）：blaze_rod(shape)、diamond(color)、emerald(pattern)、quartz(border)、stick(material)

# 走向/轴线设计（必须先想清楚，这是最重要的）
- 整根法杖只有一条主轴线（左下→右上）；杖身、握柄、水晶簇必须沿同一条斜线方向。
- 水晶簇不能“正着”竖在斜杖上：每根尖柱的方向都要与杖身轴线一致或围绕该轴线轻微分叉。
- 连接点：水晶簇底端锚定在杖身右上端端点，连接在轴线上，不悬空、不偏侧。
- 剪影可辨：去掉颜色只看形状，要能认出“斜杖 + 顶部水晶簇”。
